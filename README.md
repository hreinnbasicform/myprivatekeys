# myprivatekeys.com

Educational site about creating **SSH** and **Bitcoin (BIP39)** private keys safely.

Teach process and entropy only. **Never** generate or paste real private keys or seed phrases in this repo or on the live site.

Domain: [myprivatekeys.com](https://myprivatekeys.com) (SEO / education).

See `CONTENT-BRIEF.md` for the v1 site brief.
